# 📊 Tanmay — Data Analyst & AI/ML Specialist Portfolio

An ultra-modern, interactive, dark-mode portfolio built with high-performance Vanilla HTML5, Modern CSS Glassmorphism, and JavaScript. Specifically tailored for **Data Analytics**, **Machine Learning**, **Python**, **Power BI**, and **Advanced Excel**.

---

## ✨ Features & Architecture

- **Sleek Dark Mode & Glassmorphism:**
  - Ambient glowing gradients with `backdrop-filter: blur(16px)` frosted glass cards.
  - Curated neon accents (`#00f2fe` electric cyan, `#a855f7` vibrant purple, `#10b981` emerald green).
  - Subtle micro-animations, pulse indicators, and responsive flex/grid layouts.

- **Dynamic Hero Section:**
  - Live Typewriter effect cycling through core competencies.
  - Real-time pipeline telemetry widget with feature importance bars and terminal logging.

- **🧪 Interactive Data & ML Lab (Playground):**
  - **Live Scikit-Learn Churn Predictor:** Tweak sliders (Tenure, Spend, Support Tickets, Contract Agreement) to compute real-time churn risk percentages, SHAP feature impact breakdowns, and automated retention recommendations.
  - **Live Power BI Analytics Dashboard:** Dynamic Chart.js visualizations (Monthly Revenue with ARIMA forecast vs Actuals, Product Vertical Distribution). Filter by business segment (*Enterprise, SMB, D2C*) to see charts and KPI cards update in real time.
  - **SQL & DAX Formula Studio:** Interactive code selector with 1-click clipboard copy for complex SQL cohort retention queries, Power BI DAX measures, and advanced Excel formulas.

- **📂 Featured Case Studies & Projects:**
  - Telecom Customer Churn Prediction Engine (*Python, Scikit-Learn, XGBoost, SMOTE*)
  - Enterprise Sales & Profitability Power BI Architecture (*DAX, Star Schema, Power Query*)
  - Real Estate Valuation & Regression Model (*Random Forest, Feature Engineering*)
  - Automated Financial Audit & Reconciliation Engine (*Advanced Excel, Power Query M, VBA*)
  - Customer Feedback Sentiment & NLP Aspect Mining (*TF-IDF, Scikit-Learn*)
  - Healthcare Readmission Risk Classification (*Logistic Regression, ROC-AUC*)

- **🛠️ Interactive Skill & Category Filter:**
  - Filter across AI & Machine Learning, BI & Analytics, Languages & DB, and Libraries.

- **📬 Functional Contact Interface:**
  - Real-time client-side input validation with instant feedback toast notifications.
  - One-click copy email buttons and direct resume download trigger.
